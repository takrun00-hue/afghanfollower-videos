# پایپلاین روزانهٔ ویدیو — افغان فالور

هر اجرا **۴ ویدیوی عمودی ۱ دقیقه‌ای** می‌سازد:
۱) رشد در تیک‌تاک ۲) رشد در اینستاگرام ۳) رشد در شبکه‌های اجتماعی ۴) هوش مصنوعی برای شبکه‌های اجتماعی.

- هر ویدیو ۸ نکته دارد که از یک «بانک ۱۶ نکته‌ای» با چرخش روزانه انتخاب می‌شود، پس **هر روز متفاوت** است.
- قلاب، تیتر تلگرام و موزیک هم روزانه می‌چرخند (۳ نسخهٔ موزیک).
- فونت نمایشی مدرن (Baloo) + فونت متن (Vazirmatn) + گرافیک متحرک در پس‌زمینه.

## اجرا با یک دستور

```bash
node daily-render.mjs
```

- تاریخ مشخص: `node daily-render.mjs 2026-08-20`
- کیفیت 4K: `node daily-render.mjs --4k`  (کندتر و سنگین‌تر؛ برای انتشار روزانه 1080p پیشنهاد می‌شود)

خروجی‌ها در: `renders/daily/<تاریخ>/afghanfollower-<پلتفرم>-<تاریخ>.mp4`

## زمان‌بندی خودکار روزانه (ویندوز)

یک‌بار در PowerShell این را اجرا کن تا هر روز ساعت ۸ صبح خودکار بسازد
(کامپیوتر باید روشن باشد):

```powershell
schtasks /Create /TN "AfghanFollower Daily Videos" /TR "node \"D:\ClaudeFile\Create Videos\videos\tiktok-viral-tips\daily-render.mjs\"" /SC DAILY /ST 08:00 /F
```

- تغییر ساعت: `/ST 07:30`
- حذف زمان‌بند: `schtasks /Delete /TN "AfghanFollower Daily Videos" /F`
- اجرای فوری برای تست: `schtasks /Run /TN "AfghanFollower Daily Videos"`

> نکته: زمان‌بند فقط وقتی کار می‌کند که کامپیوتر روشن باشد. برای اجرای ابری/همیشگی
> باید در یک ترمینال تعاملی وارد HeyGen شوی یا از یک سرور استفاده کنی.

## افزودن/ویرایش محتوا

- متن نکته‌ها در `lib/content.mjs` است — هر دسته یک «بانک» (`BANKS.tiktok`, `BANKS.instagram`, `BANKS.general`, `BANKS.ai`).
- برای تنوع بیشتر، فقط نکتهٔ جدید به همان بانک اضافه کن؛ چرخش روزانه خودکار آن را استفاده می‌کند.
- قلاب‌ها (`HOOKS`) و تیترهای تلگرام (`TITLES`) هم آرایه‌اند و روزانه می‌چرخند.
- طراحی/انیمیشن مشترک در `lib/build.mjs` است (تم رنگی، فونت، موشن، آیکون‌ها).
- موزیک: `node music/synth.mjs 60 <۱|۲|۳>` سه نسخه می‌سازد → `music/bed-60s-v1..3.m4a`.
  برای جایگزینی با آهنگ دلخواه، همین فایل‌ها را عوض کن.

## گوینده فارسی (اختیاری)

این نسخه‌ها **بدون گوینده** و با زیرنویس + موزیک هستند. برای افزودن صدای فارسی،
در یک ترمینال تعاملی `npx hyperframes auth login` را اجرا و وارد HeyGen شو.
