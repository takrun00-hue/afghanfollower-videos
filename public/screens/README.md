# نامزدهای تصویر رسمی

`fetch-screens.mjs` تصویرهای منتشرشده روی سایت خودِ پلتفرم را دانلود می‌کند و در
`candidates.json` ثبت می‌کند — همه با `verified: false`.

**هیچ تصویری بدون دیدن وصل نمی‌شود.** یک لوگو را می‌شود با نام تطبیق داد؛ یک
اسکرین‌شات را نه. در همین دور، از ۲۶ نامزدِ رسمی فقط یکی واقعاً همان قابلیت را
نشان می‌داد: بقیه بنر عمومی «Creators»، لوگوی اینستاگرام، یا صفحهٔ محصولِ دیگری
بودند — همه واقعی، همه رسمی، و همه بی‌ربط به آن اسلاید.

روش کار:

```bash
node fetch-screens.mjs            # همه
node fetch-screens.mjs trial-reels # یکی
node check-media.mjs              # بررسی سلامت هر تصویرِ در حال استفاده
```

بعد نامزدها را نگاه کنید و فقط آن‌هایی را که همان صفحه را نشان می‌دهند به
`photo:` یک مرحله وصل کنید.
